OVERVIEW
PCC Academic Standing System is a program that will have a StudentBST ADT, and a driver program. StudentBST ADT will use binary search tree data structure to add new student, retrieve students based on the G#, remove all student in aprogram, promove a particular student based on G#, display all students sorder by G#, and monitor the performance and height of the tree.
        
DESIGN CONSIDERATION
The primary design of this project is to implement a Binary Search Tree (BST). This data structure is capable of handling dynamic student data record. It efficienly will do isertion, retreivel, and removal operations. This data structure will manage and store student records by g-number using the left and the right pointer which acts as a left child and right child of the tree. It will recursively do insertion, retrieval, removal, display, and monitoring. It does all of this in logarithmic average time, which gives this data structure the advantage to do tasks more efficienly than data structures like linear linked list. This data structure design will prevent memory leaks through deep copying and recurisve clean up. The design of this program will dynamically allocate memory strings, which will also prevent memory leaks. Deep-copy mechanism will allocate heap segments. There will also do deallocation through recursion. This design will have a tree structure stability during multi-node delesion. It will evaluate child subtrees and will make sure that there is total structural stability. This design will use the Data Abstraction & Problem Solving with Walls And Mirrors textbook by Frank M. Carrano and Timothy M. henry approach. We will have a StudentBST ADT that will have a consturctor, destructor, insetion, retrieval, removal, and monitor. This design will also have a client program that will pass in records to these function.

ALGORITHMS/RECURSION
This program will have recursive insertion helpers, recursive retrieval helpers, recursive removal helpers, recursive display helps, recursive height calculator, reursive node counter, and lastly recursive structure destroyer. Recusive insertion helper will traverse downward from given node refernce. It will branch left or right depending on the string comparism, and it will stop when a emtry tree leaf will be spotted and when it will reach to place the new node. Recursive retrieval helper will divide the active search space. One of the recursive removal helper will be done by G number. It will navigate down a single path and it will be responsible for pointer reassignment. Other recursive removal helper will be done by the student program. It will use post-order traversal apprach. Recursive display helper will be conducted by in-order traversal apparch. Recursive height calculate will deep path layout. Recursive Node counter will return one added to the sume of recursiv enode, and those recursive nodes count will come from both child branches. Recursive Structure Destroyer will implement a post order clearing pass. It will recursively clean up before preeing the parent objects.

It will also have public removal by program interface, along with public display interface, and public tree monitoring interface that will do all the tasks in StudentBST ADT.
